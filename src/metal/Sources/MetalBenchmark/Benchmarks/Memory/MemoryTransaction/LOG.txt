=== Memory Transaction Efficiency Analysis ===

--- Basic Read/Write Bandwidth ---
| Size | Write (GB/s) | Read (GB/s) | ReadWrite (GB/s) |
|------|--------------|-------------|------------------|
| 64K | 3.081 | 2.958 | 6.188 |
| 256K | 10.400 | 12.767 | 18.984 |
| 1024K | 31.756 | 51.502 | 68.195 |
| 4096K | 73.811 | 203.018 | 126.446 |

--- Access Pattern Analysis ---
| Pattern | Bandwidth (GB/s) | Relative to Sequential |
|---------|------------------|----------------------|
| Sequential | 12.635 | 1.00x |
| Strided x4 | 12.620 | 1.00x |
| Strided x16 | 12.878 | 0.98x |
| Temporal (16x read same) | 12.369 | 1.02x |

--- Read-Write Patterns ---
| Pattern | Bandwidth (GB/s) |
|---------|------------------|
| Write-Read | 1.469 |
| Read-Modify-Write | 1.514 |
| Bidirectional | 24.914 |

--- Atomic Operations ---
Atomic increment: 0.170 GB/s effective

--- Key Findings ---
1. Read and write bandwidth differ on unified memory architecture
2. Spatial locality (sequential vs strided) significantly impacts bandwidth
3. Temporal locality benefits from caching but unified memory limits this
4. Read-modify-write patterns are memory-bound on Apple M2
5. Atomic operations have significant overhead on unified memory
