Float2 (8B), 1024K: 24.931 GB/s

Float1 (4B), 1024K: 12.013 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.324 GB/s
Float4 Write, 256K: 7.785 GB/s
Float4 Write, 1024K: 19.638 GB/s
Float1 Write, 64K: 0.758 GB/s
Float1 Write, 256K: 2.382 GB/s
Float1 Write, 1024K: 7.628 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 11.153 GB/s
Strided (stride=4), 256K: 11.115 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.11x
Half4 vs Half1: 3.82x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
