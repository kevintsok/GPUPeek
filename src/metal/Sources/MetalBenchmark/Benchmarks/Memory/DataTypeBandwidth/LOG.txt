Float4 (16B), 1024K: 44.069 GB/s
Float2 (8B), 64K: 1.460 GB/s
Float2 (8B), 256K: 5.705 GB/s
Float2 (8B), 1024K: 21.472 GB/s
Float1 (4B), 64K: 0.729 GB/s
Float1 (4B), 256K: 2.746 GB/s
Float1 (4B), 1024K: 10.237 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.252 GB/s
Float4 Write, 256K: 7.296 GB/s
Float4 Write, 1024K: 15.379 GB/s
Float1 Write, 64K: 0.758 GB/s
Float1 Write, 256K: 2.548 GB/s
Float1 Write, 1024K: 7.997 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 11.798 GB/s
Strided (stride=4), 256K: 12.558 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.30x
Half4 vs Half1: 3.94x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
