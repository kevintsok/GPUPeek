=== Data Type Memory Bandwidth Analysis ===

--- Float Read Bandwidth ---
Float4 (16B), 64K: 3.500 GB/s
Float4 (16B), 256K: 11.715 GB/s
Float4 (16B), 1024K: 45.530 GB/s
Float2 (8B), 64K: 1.428 GB/s
Float2 (8B), 256K: 5.982 GB/s
Float2 (8B), 1024K: 25.703 GB/s
Float1 (4B), 64K: 0.690 GB/s
Float1 (4B), 256K: 2.909 GB/s
Float1 (4B), 1024K: 11.549 GB/s

--- Half Read Bandwidth ---

--- UInt8 Read Bandwidth ---

UInt8x1 (1B), 64K: 0.174 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.429 GB/s
Float4 Write, 256K: 7.941 GB/s
Float4 Write, 1024K: 19.393 GB/s
Float1 Write, 64K: 0.727 GB/s
Float1 Write, 256K: 2.325 GB/s
Float1 Write, 1024K: 7.742 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 10.981 GB/s
Strided (stride=4), 256K: 11.599 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 3.94x
Half4 vs Half1: 4.66x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
