=== Data Type Memory Bandwidth Analysis ===

--- Float Read Bandwidth ---
Float4 (16B), 64K: 2.795 GB/s
Float4 (16B), 256K: 10.357 GB/s
Float4 (16B), 1024K: 42.920 GB/s
Float2 (8B), 64K: 1.907 GB/s
Float2 (8B), 256K: 6.082 GB/s
Float2 (8B), 1024K: 22.706 GB/s
Float1 (4B), 64K: 0.977 GB/s
Float1 (4B), 256K: 2.977 GB/s
Float1 (4B), 1024K: 11.369 GB/s

--- Half Read Bandwidth ---

Half1 (2B), 64K: 0.571 GB/s

--- UInt8 Read Bandwidth ---
UInt8x4 (4B), 64K: 1.039 GB/s

UInt8x4 (4B), 1024K: 11.512 GB/s
UInt8x1 (1B), 64K: 0.264 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.422 GB/s
Float4 Write, 256K: 7.742 GB/s
Float4 Write, 1024K: 19.531 GB/s
Float1 Write, 64K: 0.681 GB/s
Float1 Write, 256K: 2.387 GB/s
Float1 Write, 1024K: 7.803 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 11.086 GB/s
Strided (stride=4), 256K: 12.813 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 3.78x
Half4 vs Half1: 3.96x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
