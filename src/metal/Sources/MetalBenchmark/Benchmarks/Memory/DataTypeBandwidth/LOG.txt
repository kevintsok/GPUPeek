Float1 (4B), 1024K: 12.583 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.152 GB/s
Float4 Write, 256K: 5.756 GB/s
Float4 Write, 1024K: 9.964 GB/s
Float1 Write, 64K: 0.535 GB/s
Float1 Write, 256K: 1.669 GB/s
Float1 Write, 1024K: 5.119 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 8.826 GB/s
Strided (stride=4), 256K: 9.828 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.08x
Half4 vs Half1: 4.28x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
