Float2 (8B), 256K: 5.019 GB/s
Float2 (8B), 1024K: 17.974 GB/s
Float1 (4B), 64K: 0.707 GB/s
Float1 (4B), 256K: 2.451 GB/s
Float1 (4B), 1024K: 8.810 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 1.995 GB/s
Float4 Write, 256K: 5.378 GB/s
Float4 Write, 1024K: 13.868 GB/s
Float1 Write, 64K: 0.738 GB/s
Float1 Write, 256K: 2.540 GB/s
Float1 Write, 1024K: 8.281 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 12.825 GB/s
Strided (stride=4), 256K: 12.790 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.22x
Half4 vs Half1: 4.05x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
