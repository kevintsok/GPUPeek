Float4 (16B), 1024K: 45.257 GB/s
Float2 (8B), 64K: 1.402 GB/s
Float2 (8B), 256K: 5.592 GB/s
Float2 (8B), 1024K: 22.137 GB/s
Float1 (4B), 64K: 0.688 GB/s
Float1 (4B), 256K: 2.784 GB/s
Float1 (4B), 1024K: 11.038 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.212 GB/s
Float4 Write, 256K: 7.318 GB/s
Float4 Write, 1024K: 12.713 GB/s
Float1 Write, 64K: 0.554 GB/s
Float1 Write, 256K: 1.985 GB/s
Float1 Write, 1024K: 5.487 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 10.537 GB/s
Strided (stride=4), 256K: 10.918 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.10x
Half4 vs Half1: 4.31x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
