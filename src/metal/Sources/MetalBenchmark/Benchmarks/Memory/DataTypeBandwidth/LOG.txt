=== Data Type Memory Bandwidth Analysis ===

Float4 (16B), 1024K: 43.573 GB/s
Float2 (8B), 64K: 1.452 GB/s
Float2 (8B), 256K: 5.906 GB/s
Float2 (8B), 1024K: 24.105 GB/s
Float1 (4B), 64K: 0.792 GB/s
Float1 (4B), 256K: 3.245 GB/s
Float1 (4B), 1024K: 12.250 GB/s

--- UInt8 Read Bandwidth ---

--- Write Bandwidth ---
Float4 Write, 64K: 2.384 GB/s
Float4 Write, 256K: 7.998 GB/s
Float4 Write, 1024K: 20.390 GB/s
Float1 Write, 64K: 0.775 GB/s
Float1 Write, 256K: 2.447 GB/s
Float1 Write, 1024K: 7.772 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 11.422 GB/s
Strided (stride=4), 256K: 11.511 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 3.56x
Half4 vs Half1: 4.65x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
