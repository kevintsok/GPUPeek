Float4 (16B), 1024K: 38.870 GB/s

Float2 (8B), 256K: 5.738 GB/s
Float2 (8B), 1024K: 20.865 GB/s
Float1 (4B), 64K: 0.785 GB/s
Float1 (4B), 256K: 3.050 GB/s
Float1 (4B), 1024K: 10.629 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.314 GB/s
Float4 Write, 256K: 6.004 GB/s
Float4 Write, 1024K: 10.490 GB/s
Float1 Write, 64K: 0.682 GB/s
Float1 Write, 256K: 2.348 GB/s
Float1 Write, 1024K: 6.215 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 11.507 GB/s
Strided (stride=4), 256K: 11.337 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 3.66x
Half4 vs Half1: 3.99x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
