Float2 (8B), 256K: 6.601 GB/s
Float2 (8B), 1024K: 25.791 GB/s
Float1 (4B), 64K: 0.830 GB/s
Float1 (4B), 256K: 3.305 GB/s
Float1 (4B), 1024K: 12.974 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.569 GB/s
Float4 Write, 256K: 8.391 GB/s
Float4 Write, 1024K: 20.886 GB/s
Float1 Write, 64K: 0.818 GB/s
Float1 Write, 256K: 2.631 GB/s
Float1 Write, 1024K: 8.513 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 13.275 GB/s
Strided (stride=4), 256K: 13.095 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 3.98x
Half4 vs Half1: 4.01x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
