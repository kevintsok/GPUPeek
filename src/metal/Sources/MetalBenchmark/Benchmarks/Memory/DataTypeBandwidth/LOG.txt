=== Data Type Memory Bandwidth Analysis ===

--- Float Read Bandwidth ---
Float4 (16B), 64K: 3.546 GB/s
Float4 (16B), 256K: 11.623 GB/s
Float4 (16B), 1024K: 44.855 GB/s
Float2 (8B), 64K: 1.414 GB/s
Float2 (8B), 256K: 5.703 GB/s
Float2 (8B), 1024K: 22.049 GB/s
Float1 (4B), 64K: 0.739 GB/s
Float1 (4B), 256K: 2.802 GB/s
Float1 (4B), 1024K: 11.402 GB/s

--- UInt8 Read Bandwidth ---

--- Write Bandwidth ---
Float4 Write, 64K: 1.953 GB/s
Float4 Write, 256K: 5.879 GB/s
Float4 Write, 1024K: 10.511 GB/s
Float1 Write, 64K: 0.560 GB/s
Float1 Write, 256K: 2.046 GB/s
Float1 Write, 1024K: 6.948 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 11.094 GB/s
Strided (stride=4), 256K: 11.046 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 3.93x
Half4 vs Half1: 4.32x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
