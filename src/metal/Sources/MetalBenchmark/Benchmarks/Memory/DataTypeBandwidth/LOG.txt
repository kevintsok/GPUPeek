Float2 (8B), 1024K: 24.206 GB/s
Float1 (4B), 64K: 0.759 GB/s
Float1 (4B), 256K: 3.144 GB/s
Float1 (4B), 1024K: 12.451 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.469 GB/s
Float4 Write, 256K: 7.947 GB/s
Float4 Write, 1024K: 20.142 GB/s
Float1 Write, 64K: 0.759 GB/s
Float1 Write, 256K: 2.594 GB/s
Float1 Write, 1024K: 8.530 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 12.563 GB/s
Strided (stride=4), 256K: 12.560 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 3.92x
Half4 vs Half1: 4.03x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
