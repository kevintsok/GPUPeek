Float2 (8B), 1024K: 19.076 GB/s
Float1 (4B), 64K: 0.698 GB/s
Float1 (4B), 256K: 2.561 GB/s
Float1 (4B), 1024K: 9.251 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.556 GB/s
Float4 Write, 256K: 8.253 GB/s
Float4 Write, 1024K: 19.802 GB/s
Float1 Write, 64K: 0.688 GB/s
Float1 Write, 256K: 2.391 GB/s
Float1 Write, 1024K: 7.723 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 11.169 GB/s
Strided (stride=4), 256K: 10.905 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.03x
Half4 vs Half1: 3.89x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
