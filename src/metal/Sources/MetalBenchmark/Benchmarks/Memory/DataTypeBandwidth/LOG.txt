Float2 (8B), 64K: 1.438 GB/s
Float2 (8B), 256K: 5.369 GB/s
Float2 (8B), 1024K: 22.704 GB/s
Float1 (4B), 64K: 0.724 GB/s
Float1 (4B), 256K: 2.765 GB/s
Float1 (4B), 1024K: 11.221 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.237 GB/s
Float4 Write, 256K: 6.857 GB/s
Float4 Write, 1024K: 13.384 GB/s
Float1 Write, 64K: 0.610 GB/s
Float1 Write, 256K: 2.110 GB/s
Float1 Write, 1024K: 5.941 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 12.321 GB/s
Strided (stride=4), 256K: 11.886 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 3.87x
Half4 vs Half1: 3.82x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
