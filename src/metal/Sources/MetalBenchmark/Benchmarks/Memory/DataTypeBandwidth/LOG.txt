Float2 (8B), 1024K: 24.014 GB/s
Float1 (4B), 64K: 0.755 GB/s

Float1 (4B), 1024K: 13.163 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.642 GB/s
Float4 Write, 256K: 8.402 GB/s
Float4 Write, 1024K: 20.636 GB/s
Float1 Write, 64K: 0.787 GB/s
Float1 Write, 256K: 2.631 GB/s
Float1 Write, 1024K: 8.398 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 13.094 GB/s
Strided (stride=4), 256K: 12.507 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 3.59x
Half4 vs Half1: 3.68x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
