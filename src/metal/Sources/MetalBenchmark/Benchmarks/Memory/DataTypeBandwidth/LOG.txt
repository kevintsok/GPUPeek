Float1 (4B), 64K: 0.701 GB/s

Float1 (4B), 1024K: 10.017 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.326 GB/s
Float4 Write, 256K: 7.780 GB/s
Float4 Write, 1024K: 21.122 GB/s
Float1 Write, 64K: 0.763 GB/s
Float1 Write, 256K: 2.565 GB/s
Float1 Write, 1024K: 8.363 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 12.568 GB/s
Strided (stride=4), 256K: 11.324 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.55x
Half4 vs Half1: 4.23x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
