Float2 (8B), 1024K: 22.796 GB/s
Float1 (4B), 64K: 0.778 GB/s
Float1 (4B), 256K: 3.084 GB/s
Float1 (4B), 1024K: 10.749 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 1.960 GB/s
Float4 Write, 256K: 5.461 GB/s
Float4 Write, 1024K: 11.235 GB/s
Float1 Write, 64K: 0.645 GB/s
Float1 Write, 256K: 1.892 GB/s
Float1 Write, 1024K: 6.311 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 10.792 GB/s
Strided (stride=4), 256K: 11.048 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.23x
Half4 vs Half1: 4.37x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
