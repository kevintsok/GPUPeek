Float4 (16B), 1024K: 47.434 GB/s
Float2 (8B), 64K: 1.383 GB/s
Float2 (8B), 256K: 5.936 GB/s
Float2 (8B), 1024K: 21.097 GB/s
Float1 (4B), 64K: 0.726 GB/s
Float1 (4B), 256K: 2.815 GB/s
Float1 (4B), 1024K: 11.157 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 1.964 GB/s
Float4 Write, 256K: 6.279 GB/s
Float4 Write, 1024K: 19.336 GB/s
Float1 Write, 64K: 0.703 GB/s
Float1 Write, 256K: 2.392 GB/s
Float1 Write, 1024K: 8.159 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 12.580 GB/s
Strided (stride=4), 256K: 12.612 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.25x
Half4 vs Half1: 4.41x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
