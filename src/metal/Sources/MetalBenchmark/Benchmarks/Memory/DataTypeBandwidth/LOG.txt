=== Data Type Memory Bandwidth Analysis ===

Float4 (16B), 1024K: 45.835 GB/s
Float2 (8B), 64K: 1.388 GB/s
Float2 (8B), 256K: 5.859 GB/s
Float2 (8B), 1024K: 21.509 GB/s
Float1 (4B), 64K: 0.733 GB/s
Float1 (4B), 256K: 2.840 GB/s
Float1 (4B), 1024K: 11.986 GB/s

--- UInt8 Read Bandwidth ---

UInt8x1 (1B), 64K: 0.171 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 1.935 GB/s
Float4 Write, 256K: 5.334 GB/s
Float4 Write, 1024K: 13.757 GB/s
Float1 Write, 64K: 0.644 GB/s
Float1 Write, 256K: 2.499 GB/s
Float1 Write, 1024K: 8.429 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 12.878 GB/s
Strided (stride=4), 256K: 12.453 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 3.82x
Half4 vs Half1: 4.70x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
