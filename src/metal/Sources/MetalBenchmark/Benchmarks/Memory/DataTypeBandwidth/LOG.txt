=== Data Type Memory Bandwidth Analysis ===

Float4 (16B), 1024K: 43.936 GB/s
Float2 (8B), 64K: 1.445 GB/s
Float2 (8B), 256K: 5.813 GB/s
Float2 (8B), 1024K: 22.277 GB/s
Float1 (4B), 64K: 0.707 GB/s
Float1 (4B), 256K: 2.828 GB/s
Float1 (4B), 1024K: 11.122 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.268 GB/s
Float4 Write, 256K: 7.566 GB/s
Float4 Write, 1024K: 19.534 GB/s
Float1 Write, 64K: 0.740 GB/s
Float1 Write, 256K: 2.470 GB/s
Float1 Write, 1024K: 8.394 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 13.022 GB/s
Strided (stride=4), 256K: 12.365 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 3.95x
Half4 vs Half1: 4.07x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
