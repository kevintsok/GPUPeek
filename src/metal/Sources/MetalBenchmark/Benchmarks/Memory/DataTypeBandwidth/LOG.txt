--- Write Bandwidth ---

Float4 Write, 256K: 8.036 GB/s
Float4 Write, 1024K: 20.377 GB/s
Float1 Write, 64K: 0.766 GB/s
Float1 Write, 256K: 2.554 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 12.647 GB/s
Strided (stride=4), 256K: 12.556 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.37x
Half4 vs Half1: 3.52x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
