Float2 (8B), 1024K: 22.044 GB/s
Float1 (4B), 64K: 0.727 GB/s
Float1 (4B), 256K: 2.904 GB/s
Float1 (4B), 1024K: 11.578 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 1.978 GB/s
Float4 Write, 256K: 5.411 GB/s
Float4 Write, 1024K: 9.937 GB/s
Float1 Write, 64K: 0.541 GB/s
Float1 Write, 256K: 1.760 GB/s
Float1 Write, 1024K: 6.483 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 11.856 GB/s
Strided (stride=4), 256K: 12.308 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 3.87x
Half4 vs Half1: 3.36x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
