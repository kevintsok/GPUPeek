Float1 (4B), 64K: 0.727 GB/s
Float1 (4B), 256K: 2.798 GB/s
Float1 (4B), 1024K: 10.845 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.306 GB/s
Float4 Write, 256K: 7.623 GB/s
Float4 Write, 1024K: 18.818 GB/s
Float1 Write, 64K: 0.646 GB/s
Float1 Write, 256K: 2.359 GB/s
Float1 Write, 1024K: 7.813 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 11.627 GB/s
Strided (stride=4), 256K: 11.377 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.19x
Half4 vs Half1: 3.35x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
