=== Data Type Memory Bandwidth Analysis ===

Float4 (16B), 1024K: 45.085 GB/s
Float2 (8B), 64K: 1.417 GB/s
Float2 (8B), 256K: 5.481 GB/s
Float2 (8B), 1024K: 22.379 GB/s
Float1 (4B), 64K: 0.704 GB/s
Float1 (4B), 256K: 2.899 GB/s
Float1 (4B), 1024K: 10.953 GB/s

--- UInt8 Read Bandwidth ---

--- Write Bandwidth ---
Float4 Write, 64K: 2.343 GB/s
Float4 Write, 256K: 7.704 GB/s
Float4 Write, 1024K: 19.651 GB/s
Float1 Write, 64K: 0.698 GB/s
Float1 Write, 256K: 2.312 GB/s
Float1 Write, 1024K: 7.726 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 11.479 GB/s
Strided (stride=4), 256K: 11.860 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.12x
Half4 vs Half1: 3.77x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
