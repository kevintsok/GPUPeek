Float2 (8B), 1024K: 22.515 GB/s
Float1 (4B), 64K: 0.697 GB/s
Float1 (4B), 256K: 2.894 GB/s
Float1 (4B), 1024K: 11.014 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.233 GB/s
Float4 Write, 256K: 6.890 GB/s
Float4 Write, 1024K: 11.434 GB/s
Float1 Write, 64K: 0.641 GB/s
Float1 Write, 256K: 2.333 GB/s
Float1 Write, 1024K: 6.793 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 10.844 GB/s
Strided (stride=4), 256K: 11.091 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.32x
Half4 vs Half1: 4.14x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
