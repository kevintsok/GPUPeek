Float2 (8B), 256K: 6.539 GB/s
Float2 (8B), 1024K: 25.861 GB/s
Float1 (4B), 64K: 0.836 GB/s
Float1 (4B), 256K: 3.258 GB/s
Float1 (4B), 1024K: 13.022 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.577 GB/s
Float4 Write, 256K: 8.286 GB/s
Float4 Write, 1024K: 20.746 GB/s
Float1 Write, 64K: 0.813 GB/s
Float1 Write, 256K: 2.637 GB/s
Float1 Write, 1024K: 8.544 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 13.329 GB/s
Strided (stride=4), 256K: 13.357 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 3.97x
Half4 vs Half1: 3.96x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
