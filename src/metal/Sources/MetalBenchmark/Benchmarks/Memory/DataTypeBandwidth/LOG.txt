Float2 (8B), 256K: 5.513 GB/s
Float2 (8B), 1024K: 21.822 GB/s
Float1 (4B), 64K: 0.702 GB/s
Float1 (4B), 256K: 2.849 GB/s
Float1 (4B), 1024K: 12.961 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 1.967 GB/s
Float4 Write, 256K: 5.794 GB/s
Float4 Write, 1024K: 16.134 GB/s
Float1 Write, 64K: 0.769 GB/s
Float1 Write, 256K: 2.515 GB/s
Float1 Write, 1024K: 8.320 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 12.548 GB/s
Strided (stride=4), 256K: 11.208 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 3.39x
Half4 vs Half1: 4.37x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
