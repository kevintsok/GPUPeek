Float4 (16B), 1024K: 45.001 GB/s
Float2 (8B), 64K: 1.417 GB/s
Float2 (8B), 256K: 5.744 GB/s
Float2 (8B), 1024K: 19.959 GB/s
Float1 (4B), 64K: 0.714 GB/s
Float1 (4B), 256K: 2.702 GB/s
Float1 (4B), 1024K: 9.743 GB/s

UInt8x1 (1B), 64K: 0.177 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.310 GB/s
Float4 Write, 256K: 7.557 GB/s
Float4 Write, 1024K: 19.728 GB/s
Float1 Write, 64K: 0.730 GB/s
Float1 Write, 256K: 2.418 GB/s
Float1 Write, 1024K: 6.435 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 9.253 GB/s
Strided (stride=4), 256K: 9.347 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.62x
Half4 vs Half1: 3.58x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
