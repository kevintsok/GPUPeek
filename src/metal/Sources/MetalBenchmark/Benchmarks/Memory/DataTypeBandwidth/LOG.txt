Float2 (8B), 1024K: 22.018 GB/s
Float1 (4B), 64K: 0.710 GB/s
Float1 (4B), 256K: 2.896 GB/s
Float1 (4B), 1024K: 10.753 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.288 GB/s
Float4 Write, 256K: 7.407 GB/s
Float4 Write, 1024K: 18.070 GB/s
Float1 Write, 64K: 0.623 GB/s
Float1 Write, 256K: 2.175 GB/s
Float1 Write, 1024K: 6.845 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 11.888 GB/s
Strided (stride=4), 256K: 11.708 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.06x
Half4 vs Half1: 4.33x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
