Float2 (8B), 1024K: 25.090 GB/s

Float1 (4B), 1024K: 12.094 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.138 GB/s
Float4 Write, 256K: 5.895 GB/s
Float4 Write, 1024K: 12.446 GB/s
Float1 Write, 64K: 0.669 GB/s
Float1 Write, 256K: 2.448 GB/s
Float1 Write, 1024K: 8.204 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 12.433 GB/s
Strided (stride=4), 256K: 12.585 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.23x
Half4 vs Half1: 4.33x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
