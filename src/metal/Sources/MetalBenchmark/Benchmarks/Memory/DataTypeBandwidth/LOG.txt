Float1 (4B), 64K: 0.710 GB/s
Float1 (4B), 256K: 2.964 GB/s
Float1 (4B), 1024K: 11.037 GB/s

--- Write Bandwidth ---
Float4 Write, 64K: 2.528 GB/s
Float4 Write, 256K: 7.893 GB/s
Float4 Write, 1024K: 19.580 GB/s
Float1 Write, 64K: 0.728 GB/s
Float1 Write, 256K: 2.339 GB/s
Float1 Write, 1024K: 7.113 GB/s

--- Access Pattern Impact ---
Sequential, 256K: 9.689 GB/s
Strided (stride=4), 256K: 11.487 GB/s

--- Vectorization Benefit ---
Float4 vs Float1: 4.14x
Half4 vs Half1: 4.10x

--- Key Findings ---
1. Float4 vectorization provides 2-4x bandwidth benefit over Float1
2. Half precision enables 2x more elements per memory transaction
3. Sequential access essential for peak memory bandwidth
4. Apple M2 unified memory limits peak bandwidth
5. Strided access severely degrades performance
