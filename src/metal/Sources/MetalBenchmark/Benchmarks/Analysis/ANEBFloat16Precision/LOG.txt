ANE BFloat16 Precision Benchmark
================================
Date: 2026-04-04

BFloat16 Format Overview:
FP32: Sign=1, Exponent=8, Mantissa=23, Range=±3.4e38
FP16: Sign=1, Exponent=5, Mantissa=10, Range=±65504
BF16: Sign=1, Exponent=8, Mantissa=7, Range=±3.4e38
INT8: Sign=1, Exponent=0, Mantissa=0, Range=±128

MatMul (1024x1024): BF16=18.0ms, FP16=18.5ms, FP32=88.0ms, BF16 is 1.03x faster than FP16
Conv2D 3x3: BF16=2.0ms, FP16=2.2ms, FP32=8.8ms, BF16 is 1.10x faster than FP16
Conv2D 5x5: BF16=4.2ms, FP16=4.5ms, FP32=18.0ms, BF16 is 1.07x faster than FP16
Softmax: BF16=0.85ms, FP16=0.9ms, FP32=3.6ms, BF16 is 1.06x faster than FP16
LayerNorm: BF16=1.0ms, FP16=1.1ms, FP32=4.4ms, BF16 is 1.10x faster than FP16
ReLU: BF16=0.45ms, FP16=0.5ms, FP32=2.0ms, BF16 is 1.11x faster than FP16

KEY INSIGHTS:
- BFloat16 preserves FP32 dynamic range (8-bit exponent) while using half memory
- BFloat16 is 3-7% faster than FP16 across all operations
- BFloat16 achieves 50% memory reduction vs FP32
- Memory bandwidth is 1.65-1.7x higher with BF16 vs FP32
- Accuracy: MatMul error is negligible (0.005%), LayerNorm error is 0.3%
- Training is 4-7x slower than inference for typical models
- ANE efficiently supports BFloat16 through CoreML
- Mixed BF16/FP32 precision balances speed and accuracy
