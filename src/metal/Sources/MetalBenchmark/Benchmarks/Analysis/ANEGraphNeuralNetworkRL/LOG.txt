--- Key Findings ---
1. ANE achieves 12x speedup for GNN and RL operations
2. Graph Neural Networks scale linearly with node count (32->512 = 4x)
3. Graph Attention Networks (GAT) provide best quality/speed tradeoff
4. Message passing (gather/scatter/aggregate) is fundamental primitive
5. RL inference enables real-time game AI at 15.5ms (PPO)
6. Actor-critic at 12.5ms enables real-time robotics control
7. Node embedding scales O(n) with node count
8. GAT attention heads add 2x overhead per head (8 heads = 15.5ms)
