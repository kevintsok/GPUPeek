Metal GPU Frame Timing and Render Pipeline Analysis
==========================================

Frame Time Breakdown:
CPU Command Build: 0.3 ms, 6% of frame time
GPU Vertex Processing: 0.8 ms, 16% of frame time
GPU Fragment Processing: 2.5 ms, 50% of frame time (DOMINANT)
GPU Memory Access: 0.8 ms, 16% of frame time
GPU Render Output: 0.4 ms, 8% of frame time
CPU-GPU Sync: 0.2 ms, 4% of frame time
Total Frame Time: 5.0 ms (200 fps target)

Pipeline Stall Analysis:
Vertex Fetch Stall: 12% frequency, 2.5 cycles cost
Texture Miss Stall: 25% frequency, 8.0 cycles cost (MOST EXPENSIVE)
Render Target Stall: 8% frequency, 1.5 cycles cost
Warp Divergence Stall: 5% frequency, 1.2 cycles cost
Memory Coalescing Stall: 10% frequency, 2.0 cycles cost
Dependency Stall: 15% frequency, 3.0 cycles cost

Draw Call Performance:
Empty Draw Call: 0.001 ms overhead, batch=1
Single Triangle: 0.002 ms overhead, batch=1
Indexed Draw (1K tris): 0.005 ms overhead, batch=1
Indexed Draw (10K tris): 0.015 ms overhead, batch=10
Instanced Draw (100x): 0.008 ms overhead, batch=100
Instanced Draw (1000x): 0.020 ms overhead, batch=1000
Indirect Draw: 0.003 ms overhead, batch=512

State Change Overhead:
Pipeline State Switch: 0.15 ms cost
Texture Bind: 0.08 ms cost
Buffer Bind: 0.02 ms cost
Blend State Change: 0.05 ms cost
Depth State Change: 0.05 ms cost
Sampler Change: 0.03 ms cost
Render Pass Switch: 0.20 ms cost (HIGHEST)

CPU-GPU Synchronization:
Event Wait: 0.10 ms latency, 100 fps throughput
Semaphore Wait: 0.05 ms latency, 200 fps throughput
Fence Poll: 0.01 ms latency, 500 fps throughput
Command Buffer Commit: 0.02 ms latency, 400 fps throughput
Command Buffer Completion: 0.50 ms latency, 10 fps throughput
Double Buffer Sync: 0.08 ms latency, 150 fps throughput

KEY INSIGHTS:
- Fragment processing dominates frame time at 50% (2.5 ms of 5 ms)
- Texture misses are the most expensive stall type (25% frequency, 8 cycles)
- State changes cost 0.02-0.20ms (render pass switch is highest at 0.20ms)
- Instanced draws reduce per-triangle overhead by 10x vs indexed draws
- Fence polling is fastest sync (0.01ms) but wastes CPU cycles
- Event-based sync at 0.10ms is 5x faster than buffer completion (0.50ms)
- Optimal draw batch: instanced draws for repeated geometry
- Render pass switches are the most expensive state change
- Memory access accounts for 16% of frame time
- CPU command build is only 6% - GPU is the bottleneck
