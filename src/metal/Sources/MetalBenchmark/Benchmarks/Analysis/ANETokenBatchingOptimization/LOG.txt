KEY INSIGHTS:
1. Batch size 1: Lowest latency, but lowest throughput
2. Optimal batch size: 8-32 for balanced latency/throughput
3. Throughput scales sub-linearly with batch size
4. Per-token latency decreases with batch size
5. Memory footprint grows linearly with batch size
6. Greedy decoding is fastest; beam search has overhead
