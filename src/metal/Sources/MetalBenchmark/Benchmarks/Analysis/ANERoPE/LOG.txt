KEY INSIGHTS:
1. Fused implementation is 6x faster than basic (41μs vs 245μs)
2. Time per token is ~140ns (constant regardless of sequence length)
3. sin/cos computation is ~40% of total time
4. Memory grows linearly with seq_len (32KB per 1024 tokens for Q/K)
5. Llama3 extended context adds 10-15% overhead
6. Fused RoPE+attention reduces memory bandwidth by 30%
7. ANE achieves 12-15x speedup vs CPU for RoPE
