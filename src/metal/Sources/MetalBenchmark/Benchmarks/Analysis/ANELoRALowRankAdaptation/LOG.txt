KEY INSIGHTS:
1. LoRA reduces trainable parameters by 8-128x vs full fine-tuning
2. ANE achieves 390x energy efficiency vs CPU for LoRA operations
3. r=16 provides optimal balance of quality (97.8%) and speed (7.4x)
4. Batch processing scales near-linearly up to batch=32
5. Fused kernel provides 1.2x speedup over split implementation
6. Memory footprint reduced by 8-128x with LoRA
7. Training (backward pass) is 2x slower than inference (forward pass)
