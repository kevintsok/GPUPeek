KEY INSIGHTS:
- FNO achieves 12-13x speedup over CPU for FFT operations
- Spectral convolutions are 8-18x faster than spatial convolutions
- Mode truncation provides 8-64x parameter compression with minimal accuracy loss
- Global receptive field achieved in single layer vs 10-20 layers for CNNs
- ANE's sinusoidal computation units are well-suited for FFT operations
