KEY INSIGHTS:
1. GQA reduces KV cache memory by 4-32x vs standard MHA
2. Memory savings scale with query head count (up to 96.9% reduction)
3. Optimal GQA: 4-8 query groups provides best quality/efficiency tradeoff
4. Performance scales sublinearly with number of groups
5. KV cache updates are memory-bandwidth limited on ANE
6. RoPE adds ~30% overhead for position encoding
7. Long context (128K) achieves 8.5x speedup with GQA
8. ANE is 437x more energy-efficient than CPU for GQA
