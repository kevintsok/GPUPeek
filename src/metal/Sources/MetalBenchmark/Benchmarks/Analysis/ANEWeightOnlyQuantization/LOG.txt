KEY INSIGHTS:
1. INT8 provides 4x memory reduction with ~2.7x speedup in matmul
2. INT4 provides 8x memory reduction with faster quantization (892μs vs 1842μs)
3. Per-channel quantization is slower (3524μs) but preserves more accuracy
4. Batch processing amortizes quantization overhead: batch=8 has 3.7x overhead vs 1x for batch=1
5. For 70B model: INT8 saves 210GB, INT4 saves 245GB
6. ANE weight-only quantization enables large model inference on memory-constrained devices
