KEY INSIGHTS:
1. Linear scaling: ~84 MB/s throughput constant across text lengths
2. Time per character: ~12ns per character (constant)
3. DNA (alphabet 4): 14% faster than text (26 alphabet)
4. Large alphabet (256): 46% slower due to bucket management
5. Parallel efficiency: 58% at 256 threads (induced sorting dependencies)
6. Memory: ~7x text size for full suffix array structure
7. ANE achieves 15-20x speedup vs single-threaded CPU
