--- Key Findings ---
1. ANE has lower latency than GPU for tensor operations
2. ANE bandwidth: ~50-80 GB/s (lower than GPU peak)
3. ANE optimized for sequential and strided access
4. ANE memory efficiency: 85-95% for tensor workloads
5. ANE memory footprint: 20% smaller than GPU
6. ANE broadcast efficiency: Best for weight broadcasting
