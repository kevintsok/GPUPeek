KEY INSIGHTS:
1. Dynamic routing is 35-48% of total CapsNet computation time
2. ANE is 98x more energy-efficient than CPU for Capsule Networks
3. Routing iterations provide diminishing returns after 3 iterations
4. Matrix multiply for capsule transform scales O(primary × output)
5. Squashing function is highly efficient on ANE (0.03-0.15ms)
6. Capsule dimension doesn't significantly impact margin loss time
