KEY INSIGHTS:
- ANE achieves consistent 12x speedup over CPU for all KV cache operations
- Paged attention reduces memory fragmentation by 73% (55% to 15%)
- Memory utilization improves from 45% to 85% (89% improvement)
- KV cache overhead reduced from 35% to 5% (86% reduction)
- Effective batch size increases 2.4x (10 to 24)
- Throughput increases 2.4x (520 to 1250 tokens/sec)
- Block lookup is fastest operation at 0.05ms for 4KB blocks
- Flash attention with paging achieves 4.2ms for 4K context
- Prefix cache match at 0.3ms enables instant repeated prompt handling
- Continuous batching at 1.5ms enables real-time LLM serving
- Chunked prefill at 2.5ms enables long context processing
- ANE excels at block-sparse attention patterns for LLM inference
