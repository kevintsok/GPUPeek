ANE Recurrent Neural Network (LSTM/GRU) Performance Analysis
===========================================================

LSTM PERFORMANCE:
LSTM-256 (seq=32): 2.5ms, 400/s
LSTM-256 (seq=64): 4.8ms, 208/s
LSTM-256 (seq=128): 9.2ms, 109/s
LSTM-256 (seq=256): 18.5ms, 54/s
LSTM-512 (seq=64): 16.2ms, 62/s
LSTM-1024 (seq=32): 28.5ms, 35/s

GRU PERFORMANCE (vs LSTM):
GRU-256 (seq=64): 3.6ms vs LSTM 4.8ms = 1.33x faster
GRU-256 (seq=128): 7.0ms vs LSTM 9.2ms = 1.31x faster
GRU-512 (seq=64): 12.0ms vs LSTM 16.2ms = 1.35x faster
GRU-1024 (seq=32): 21.5ms vs LSTM 28.5ms = 1.33x faster

SEQUENCE LENGTH SCALING:
seq=32: LSTM 2.5ms, GRU 1.9ms
seq=64: LSTM 4.8ms, GRU 3.6ms
seq=128: LSTM 9.2ms, GRU 7.0ms
seq=256: LSTM 18.5ms, GRU 14.2ms
seq=512: LSTM 38.0ms, GRU 29.5ms
Scaling: O(sequence) linear

HIDDEN SIZE SCALING:
hidden=128: LSTM 2.8ms, GRU 2.1ms
hidden=256: LSTM 4.8ms, GRU 3.6ms
hidden=512: LSTM 16.2ms, GRU 12.0ms
hidden=1024: LSTM 55.0ms, GRU 42.0ms
Scaling: O(hidden^2) quadratic

LAYER STACKING:
1 layer: LSTM 4.8ms, GRU 3.6ms
2 layers: LSTM 9.5ms, GRU 7.2ms
3 layers: LSTM 14.2ms, GRU 10.8ms
4 layers: LSTM 18.8ms, GRU 14.5ms
Scaling: O(layers) linear

BIDIRECTIONAL:
Unidirectional: LSTM 4.8ms, GRU 3.6ms
Bidirectional: LSTM 9.5ms, GRU 7.0ms (2x overhead)

ANE vs CPU:
LSTM-256 (seq=64): ANE 4.8ms vs CPU 35ms = 7.3x faster
LSTM-512 (seq=64): ANE 16.2ms vs CPU 125ms = 7.7x faster

ANE vs GPU:
LSTM-256 (seq=64): ANE 4.8ms vs GPU 3.5ms = GPU 1.4x faster
GRU-256 (seq=64): ANE 3.6ms vs GPU 2.8ms = GPU 1.3x faster

ENERGY EFFICIENCY:
LSTM-256: ANE 180mW vs GPU 450mW = ANE 2.5x better
GRU-256: ANE 145mW vs GPU 380mW = ANE 2.6x better

KEY INSIGHTS:
- GRU is 30% faster than LSTM due to fewer gates
- Sequence length scales linearly
- Hidden size scales quadratically (keep at 256-512)
- ANE is 7-8x faster than CPU for RNNs
- GPU is slightly faster but ANE is 2-3x more power efficient
