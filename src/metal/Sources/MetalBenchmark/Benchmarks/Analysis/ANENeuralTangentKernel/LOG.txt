KEY INSIGHTS:
1. ANE achieves 12-14x speedup for NTK computations
2. NTK kernel matrix computation scales O(n²) with points
3. Second-order NTK has 1.77x overhead vs first-order
4. Conjugate kernel (CK) is 1.3x faster than full NTK
5. Network width affects NTK regime - wider networks approach infinite-width limit
6. Training dynamics simulation shows ANE enables real-time infinite-width analysis
7. 18-19x more energy efficient than GPU for NTK operations
