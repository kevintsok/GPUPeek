KEY INSIGHTS:
1. Backward pass is 2-2.2x slower than forward pass for all operations
2. GEMM has lowest forward/backward overhead (2.1x)
3. Gradient checkpointing trades compute for memory efficiently
4. FP16 mixed precision achieves 2x speedup with minimal accuracy loss
5. INT8 quantization achieves 2.8x speedup but requires calibration
6. Inference is 3.8x faster than training at equivalent batch sizes
7. ANE is 5x more energy efficient than GPU for training
