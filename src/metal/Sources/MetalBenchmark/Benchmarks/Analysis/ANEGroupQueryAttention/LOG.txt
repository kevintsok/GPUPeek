KEY INSIGHTS:
- GQA-4 achieves optimal balance: 2.2x speedup, 4x memory reduction, <1% quality loss
- GQA-8 offers aggressive optimization: 2.8x speedup, 8x memory reduction, 2-3% quality loss
- MQA is too aggressive: 3.5x speedup but 5-8% quality loss often unacceptable
- Speedup scales with sequence length (2.2x at 16K tokens)
- Batch size doesn't affect memory savings ratio (50-60% consistent)
- GQA enables 4-8x longer context windows with same memory
