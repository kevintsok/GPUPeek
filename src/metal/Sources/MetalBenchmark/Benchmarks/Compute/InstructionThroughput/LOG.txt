(id + i) % size causes memory latency to dominate, masking true
instruction throughput differences.

--- Key Observations ---
1. All instructions show similar throughput (0.2-0.5 GOPS)
2. This indicates memory-bound behavior dominates
3. True instruction throughput differences are masked by memory latency
4. To measure true instruction throughput, need sequential access pattern

--- Cost Classification (Theoretical) ---
| Category | Instructions | Expected Cost |
|----------|--------------|--------------|
| CHEAP (1 cycle) | ADD, MUL, FMA, MIN, MAX, ABS | 1x |
| MODERATE (4-8 cycles) | DIV, SQRT, RCP | 4-8x slower |
| EXPENSIVE (8-20 cycles) | EXP, LOG, POW, SIN, COS | 8-20x slower |
| VERY EXPENSIVE (20+ cycles) | TANH | 20x+ slower |

--- Optimization Recommendations ---
1. Use FMA over separate mul+add when possible (single instruction)
2. Replace division with reciprocal multiplication when accuracy allows
3. Use fast math approximations (sinf, cosf, expf) for reduced precision
4. Precompute expensive functions in lookup tables for real-time apps
5. Consider Taylor series approximations for simple transcendental functions
