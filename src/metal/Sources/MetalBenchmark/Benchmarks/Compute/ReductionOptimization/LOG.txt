--- Key Findings ---
1. Tree-based parallel reduction is 2-3x faster than naive for all sizes
2. Shared memory reduction is 3-5x faster than parallel for large sizes
3. Warp-level reduction achieves highest throughput for sum (96+ M elem/s)
4. Multi-warp reduction is best overall, achieving 127 M elem/s for 1M elements
5. For max reduction, shared memory is 5x faster than parallel for 1M elements
6. Apple M2 unified memory benefits from threadgroup-local reductions
