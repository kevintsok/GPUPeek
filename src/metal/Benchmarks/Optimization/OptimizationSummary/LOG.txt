--- Key Insights ---
1. Apple M2 operates predominantly in MEMORY BOUND regime
2. Unified memory architecture shares bandwidth with CPU (~2 GB/s effective)
3. Memory coalescing provides the biggest optimization (5.3x)
4. Kernel fusion and batching provide consistent speedups
5. Multi-queue does NOT help (0.76x slower) due to overhead

--- Priority Optimization Order ---
P0 (Must Do):
1. Ensure coalesced memory access
2. Use Float4/Half4 vectorization
3. Burst write (16+ elements per thread)
4. Use FP16 for ML/inference

P1 (Should Do):
5. Implement shared memory tiling for GEMM/Stencil
6. Fuse multiple kernels into one
7. Batch command buffers
8. Use 4x4 register blocking

P2 (Can Do):
9. Tune threadgroup size (256 vs 512)
10. Use async execution for independent kernels
11. Use FMA instead of mul+add

P3 (Avoid):
- Multi-queue (overhead doesn't pay off)
- Dynamic shader generation at runtime
- Small batch sizes without profiling
