5. Apple M2 unified memory affects bandwidth characteristics

--- Analysis ---
- Float4 vs Float1: Vectorization typically 2-4x better
- Half vs Float: Half has 2x density but same transaction overhead
- Int8: Highest density but conversion overhead
- Strided: Poor cache line utilization
- Random: No spatial locality, worst performance

--- Recommendations ---
1. Use vectorized types (float4, half4) when possible
2. Prefer half precision for memory-bound operations
3. Avoid strided access patterns
4. Consider data layout changes for better vectorization
