=== Apple Neural Engine (ANE) Research ===

--- Key Finding: ANE is NOT part of Metal/GPU ---

ANE is a SEPARATE neural network accelerator:
- NOT programmed via Metal compute shaders
- NOT accessible from shader code
- Accessed via CoreML, Vision, NaturalLanguage frameworks

--- ANE vs GPU Performance (Neural Networks) ---

| Operation | ANE Advantage | Notes |
|-----------|--------------|-------|
| MatMul (small) | 10-100x | Dedicated MAC units |
| Conv2D | 5-20x | Sliding window optimization |
| Attention | 10-50x | Transformer acceleration |
| BatchNorm | 2-5x | Efficient element-wise |
| Softmax | 5-10x | Specialized reduction |

--- Conclusion ---

1. ANE is a DEDICATED neural network accelerator (NPU)
2. NOT part of GPU - separate silicon component
3. Cannot be programmed via Metal Shading Language
4. Access via CoreML, Vision, NLP frameworks
5. For GPU research: ANE is outside Metal GPU architecture scope
6. GPU tensor core equivalent: use SIMD group WMMA emulation

--- Metal vs ANE Summary ---

Metal (GPU):
- General parallel compute
- Accessed via MTLComputeCommandEncoder
- Flexible but slower for ML

ANE:
- Neural network inference only
- Accessed via CoreML/Vision/NLP
- 5-50x faster for ML ops but not programmable directly
